# Футбольный бот-агрегатор для Telegram

Бот собирает футбольные новости из открытых источников и присылает их тебе в личку. Дальше ты сам выбираешь новость, добавляешь фото или видео и публикуешь в канал.

**Что приходит:**

- **Новости** по АПЛ, Ла Лиге, Бундеслиге, Серии А, Лиге 1, Лиге чемпионов, Лиге Европы, Лиге конференций и Лиге наций, а также о топ-игроках и тренерах.
- **🏁 Итоги матчей** этих турниров: финальный счёт, голы с минутами (пенальти и автоголы отмечены), удаления и стадион. Приходят через несколько минут после финального свистка.
- **📅 Анонс дня**: каждое утро список сегодняшних матчей со временем начала.

У каждой новости есть превью статьи с картинкой и кнопки: **🔗 Открыть источник**, **✅ Взял** (пометить использованное) и **🗑 Удалить**.

Как бот отбирает новости:

- Отсеивает РПЛ, МЛС, женский и юношеский футбол.
- Склеивает дубли: если одну новость написали пять сайтов, придёт одна.
- Не присылает лавину старых новостей при первом запуске и после паузы.

## Быстрый старт (Windows)

1. Токен уже лежит в `.env` (`BOT_API=…`). Больше ничего заполнять не обязательно.
2. Дважды кликни **`run.bat`**. При первом запуске он сам создаст виртуальное окружение и поставит зависимости.
3. Открой своего бота в Telegram и нажми **/start**. Кто первым нажмёт /start, тот становится владельцем, и для остальных бот закрыт.
4. Бот сразу пришлёт 3 свежие новости для примера. Дальше новости приходят по мере выхода, источники проверяются каждые 3 минуты.

Остановить бота: **Ctrl+C** в окне консоли.

**Запуск из терминала** (например, в VS Code), из папки проекта:

```powershell
.venv\Scripts\python main.py
```

Если окружение активировано (`.venv\Scripts\activate`), достаточно `python main.py`. `python -m bot` работает так же.

> ⚠️ **Если бот пишет «Нет связи с Telegram»**, значит провайдер блокирует Telegram Bot API (`api.telegram.org`). Сайты с новостями при этом работают. Есть три варианта:
> 1. Включить на компьютере VPN, который пускает весь трафик через себя.
> 2. Указать прокси только для Telegram в `.env`, например `TELEGRAM_PROXY=socks5://логин:пароль@1.2.3.4:1080`. Подходят http, https, socks4 и socks5.
> 3. **Лучший вариант:** запустить бота на VPS за рубежом (от ~$3–5 в месяц). Так он будет работать круглосуточно, даже когда компьютер выключен. Инструкция ниже.

## Кнопки меню

Бот управляется кнопками внизу экрана. Меню появляется после /start. Если кнопки пропали, снова нажми /start.

| Кнопка | Что делает |
|---|---|
| 📰 Последние новости | 5 последних новостей |
| 📅 Матчи сегодня | Время матчей, текущий счёт идущих, итог завершённых |
| 🔄 Проверить сейчас | Проверить источники, не дожидаясь следующей проверки |
| 📊 Статус | Какие источники работают, сколько отправлено за сегодня |
| ⚙️ Настройки | Включить или выключить турниры, «Звёзды», «Прочее», английские источники, итоги матчей и анонс |
| ⏸ Пауза / ▶️ Продолжить | Остановить и возобновить сбор. Новости, вышедшие за время паузы, не придут |
| ❓ Помощь | Справка |

Если нужно больше 5 последних новостей, напиши `/latest 10` (максимум 20). Остальные старые команды (`/status`, `/check` и т.д.) тоже работают, но в меню Telegram их больше нет.

**Английские источники** (BBC, The Guardian, Sky Sports, Football Italia, Football España, Get French Football News, Bulinews) по умолчанию выключены. Они на английском и часто дублируют русские новости. Включаются в «⚙️ Настройки».

## Настройки `.env`

Все параметры необязательные, кроме токена. Полный список с пояснениями есть в [.env.example](.env.example).

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` или `BOT_API` | — | Токен от @BotFather |
| `ADMIN_IDS` | пусто | Telegram ID получателей через запятую. Если пусто, владельцем станет первый, кто нажмёт /start |
| `TIMEZONE` | часовой пояс ПК | Например `Asia/Almaty`, `Europe/Moscow` |
| `DIGEST_TIME` | `09:00` | Время утреннего анонса |
| `NEWS_INTERVAL_SEC` | `180` | Как часто проверять новости |
| `MATCHES_INTERVAL_SEC` | `300` | Как часто обновлять счёт во время матчей |
| `MAX_NEWS_AGE_HOURS` | `3` | Новости старше этого не присылаются |
| `TELEGRAM_PROXY` | пусто | Прокси для Telegram, если он заблокирован |
| `TELEGRAM_API_URL` | пусто | Свой сервер Bot API или обратный прокси |

Чтобы новости получали несколько человек, перечисли их ID в `ADMIN_IDS`. Свой ID человек узнает, если напишет боту /start.

## Источники

| Русские | Английские |
|---|---|
| Sports.ru, Чемпионат, Спорт-Экспресс, Soccer.ru, Рамблер Спорт | BBC Sport, The Guardian, Sky Sports, Football Italia, Football España, Get French Football News, Bulinews |

- **Новости:** RSS-ленты сайтов.
- **Матчи:** открытое API ESPN (ключ не нужен).
- **Добавить источник:** допиши строку `Source(...)` в [bot/sources.py](bot/sources.py) и перезапусти бота. Новый источник при первой загрузке молча запоминает свои текущие новости, поэтому лавины не будет.
- **Проверить фильтры без Telegram:** выполни `python -m bot --preview`. Бот один раз соберёт новости и покажет в консоли, что бы он отправил, что посчитал дублями и что отсеял.

### Раз в сезон: обновить состав лиг

Списки клубов лежат в [bot/catalog.py](bot/catalog.py) и сейчас соответствуют сезону 2026/27. Летом, после повышений и вылетов, добавь новые клубы и убери вылетевшие. Там же список «Звёзд»: игроки и тренеры, новости о которых приходят даже без упоминания клуба.

## Запуск на сервере (Linux VPS)

```bash
sudo apt install -y python3.11 python3.11-venv git
cd /opt && sudo git clone <репозиторий> footbalBot   # или скопируй папку через scp
cd /opt/footbalBot
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
nano .env   # BOT_TOKEN=..., TIMEZONE=Asia/Almaty
```

Чтобы бот работал постоянно и сам перезапускался, создай файл `/etc/systemd/system/footbalbot.service`:

```ini
[Unit]
Description=Football news bot
After=network-online.target
Wants=network-online.target

[Service]
WorkingDirectory=/opt/footbalBot
ExecStart=/opt/footbalBot/.venv/bin/python -m bot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Затем включи и запусти сервис, а логи смотри через journalctl:

```bash
sudo systemctl enable --now footbalbot
journalctl -u footbalbot -f   # логи
```

> Одновременно может работать только **одна копия** бота с этим токеном. Если запустил на сервере, на компьютере его нужно остановить.

## Для разработки

```bash
pip install -r requirements-dev.txt
python -m pytest          # 65 тестов: фильтры, дубли, разбор матчей, формат сообщений, весь цикл
python -m bot --preview   # пробный сбор новостей в консоль
```

Логи пишутся в `logs/bot.log`, база данных лежит в `data/bot.sqlite3`. Если удалить базу, бот начнёт с чистого листа, и владельцем снова станет первый, кто нажмёт /start.

Структура пакета `bot/`:

- `catalog.py`: турниры, клубы, звёзды и переводы названий команд;
- `classifier.py`: определяет, о каком турнире и клубе новость;
- `sources.py`: список RSS-источников;
- `news.py`: сбор, фильтрация, поиск дублей и доставка новостей;
- `espn.py`, `matches.py`: матчи, итоги и анонс дня;
- `render.py`, `texts.py`, `keyboards.py`: тексты сообщений и кнопки;
- `handlers.py`: команды и кнопки бота;
- `app.py`: запуск и фоновые циклы.

## Ограничения

- **Классификация по ключевым словам.** Она работает хорошо, но не идеально: редко новость может попасть не в ту лигу или не пройти фильтр. Если включить «Прочее» в «⚙️ Настройки», будут приходить все футбольные новости, кроме явно нерелевантных.
- **Фото и видео бот не прикладывает.** Права на них обычно принадлежат агентствам и лигам. В превью ссылки видна картинка статьи, чтобы было проще найти, что поставить в пост.
- **API ESPN неофициальное.** Если ESPN его поменяет, итоги матчей временно перестанут приходить, а новости продолжат работать. Ошибка будет видна в «📊 Статус».
